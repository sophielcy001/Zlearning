# 智学最小原型

双击本目录的 `start-demo.cmd` 启动本地服务，浏览器会自动打开。首次启动需要 Node.js 22.12 或更新版、Python 3.11 或更新版、`uv`，以及用于安装依赖的网络连接。原型运行使用本地样例，无需配置模型密钥。

首次打开空白安装时，先在引导中确认默认保存目录，或输入本机新文件夹或空文件夹的绝对路径。SQLite 学习记录和 library 知识库放在同一目录。接着可以设置主模型和复核模型、查看测试结果，也可以稍后设置并进入首页。已有学习数据的安装会直接打开原工作区。

## 从首页体验学习闭环

1. 选择 **体验 SQLite 样例**，修改目标卡，点击 **提交并生成路线**。三节课准备完成后，可直接打开任一节。
2. 打开 **理解表、行和列**，查看正文与来源，写并保存一条笔记。可手动开始、暂停或结束计时。
3. 点击 **标为已学完**，进入 **今日复习**。两个知识目标先列在后续安排中。点击 **推进试用日期一天**，选择一个目标作答。提交后可查看评价及下一次复习日期。
4. 在 **知识库** 搜索课程、笔记和导入的 UTF-8 TXT、Markdown、PDF 或 DOCX。点击命中可查看相应的文本行、PDF 页或 Word 段落及表格行。「关键词＋语义」的结果可展开「语义命中片段」，核对完整的匹配正文。语义索引损坏时，可用提示中的「重试」或点击「重建索引」，期间仍可搜索关键词。在「最近访问」内，关键词和语义命中都按文件打开顺序排列。切换文件与图谱、在知识库内打开双链或反向链接、从原文返回列表或刷新页面时，检索条件随当前知识库地址保存。移入回收站前，可展开预览查看当前通过双链引用原件的文件及引用位置数量。原路径双链可以查看回收、清理或恢复后的状态。旧路径同时对应其他资料时会显示各候选及其状态。重启同一入口可继续原有项目和复习。
5. 扫描 PDF 可在原页下选择 **识别本页**，PNG、JPG 和 JPEG 可选择 **识别图片**。本机中英文识别完成后，对照原件修改草稿，再选择 **保存校对文字**。识别不到文字时可手动录入。已保存的文字可按原页搜索和引用，原件可直接下载。
6. 在知识库选择 **导入网页**，保存公开网页的 HTML 快照。快照记录来源、导入时间和已提取分节，搜索可定位对应分节，随时可下载快照。再次导入相同内容时可打开已有快照或保存副本。网页由服务器返回的 HTML 提取正文，动态交互内容通过来源链接打开。网页导入使用系统 DNS。系统返回代理占位地址时，通过 Cloudflare Public DNS 查询该域名。
7. 首页、对话、目标卡文字字段和文字复习题可点麦克风。选择普通话或英语后主动开始录音，结束后在本机识别。你可以修改录音草稿，再填入当前输入框，提交仍由页面上的按钮完成。桌面窗口隐藏、最小化或离开页面时会释放活动录音，原输入保留。

输入其他主题会得到可编辑目标和通用学习练习模板。SQLite 样例提供带参考链接的内置讲义及确定性评分。模板有自己的内容和路线，等课程依据补齐后才安排对应复习。试用日期仅改变当前原型数据的排期体验。

扫描资料和图片的预览内可打开「校对版本」，查看已保存的文字和差异。恢复同份原件的旧校对后，知识库按恢复的文字搜索。原件换版前的校对文字可继续查阅。若 PDF 换版后页数变少，可从现有任一页打开「校对版本」，在「选择校对页」中查阅标有「仅历史」的页面。清理回收站中的扫描原件会一并清除校对版本。

## 自由聊天

在管理中心配置主模型后，可从首页选择 **用主模型聊天**，也可在「聊天」中新建或继续对话。确认前会显示接收模型、请求地址、当前问题和所选的近期问答，附件留在本机。关闭预览会保留草稿。回复完成后，可以继续追问，或主动选择 **整理为学习目标**。

聊天和课内助手共用「教学风格」。可以在「直接讲解」和「启发式引导」之间切换，后续问题沿用当前选择。自由聊天发送预览会显示本轮风格。

在课内助手或关联课程的对话中，可以发出「这节我已经会了」「把这个知识点提前」「修改我的学习目标」。用键盘输入，或主动录音并核对识别草稿后发送。预览确认后，第一条更新个人标记，第二条把当前节向前移动一位，第三条保存当前项目的目标与日期。

回复共用已配置的模型并发与每日额度。遇到额度暂停可在「额度恢复」继续，其他失败可从原消息重新确认。对话、已完成回复和待回复状态保存在当前工作区。

在自由聊天选择已授权 Skill 的专业 Agent 后，可以按当前问题自动匹配、手动指定一项或不附带 Skill。自动匹配在本机读取已授权 Skill 的名称和简介。发送预览显示选中的版本和可展开的原文。只有点击「确认发送」后才会使用所选模型。

专业 Agent 可在「知识范围」授权本机文件夹。对话发送预览可输入关键词，从已授权文件夹提取少量正文片段。确认之前可查看片段或移除检索。检索结果作为引用显示在对话中。

在「管理中心 → 能力库」可按工具、MCP、Skills 查看当前能力。内置知识库检索显示授权的 Agent 和实际目录状态。Skills 显示是否安装、是否已有 Agent 授权，以及历史中是否有较新版本。授权仍在专业 Agent 配置中确认。

在「管理中心 → 记忆」可以查看共享、Agent 专属与待确认记录。聊天中的用户原话也可主动保存。共享项在确认前进入待确认，Agent 专属项可申请共享。删除停用后，原对话可继续查看。

在「待确认」勾选多条并点「修改所选」，可在同一窗口核对原内容和来源，再一次保存编辑。保存后继续等待共享确认。记录已被其他窗口修改时，当前输入保留在对话框中，关闭后可重新核对当前版本。

在专业 Agent 配置中，可分别授予读取共享记忆和自身专属记忆的权限。聊天发送预览可逐条选择本轮附带的记忆，确认前可以核对原文或移除。发送前会再次核对权限和版本。

聊天中的「AI 整理记忆」可从所选原话生成建议。核对发送内容、接收模型和保存范围后提交一次后台任务。生成的条目标为「AI 推断」，共享建议由用户确认后生效。

在专业 Agent 配置中可开启「自动整理专属记忆」。授权绑定配置中确认的模型连接。每次新问题收到回复后，只把本轮原话发给同一模型进行一次整理，建议留在所选 Agent 的专属范围。整理请求计入额度，管理中心可查看任务或取消。恢复备份会关闭持续授权，重新启用须确认。

在记忆管理中可选配 Mem0。先确认允许的发送范围，再逐条核对与确认外部保存。删除本地记忆立即停用，Mem0 独立验证删除结果，失败可重试。可移除外部副本并保留本地记忆。便携备份只包含本地记忆，同机恢复会暂停外发并保留当前安装的删除跟踪。

能力库可配置 GitHub 和 GitLab.com 官方只读 MCP。指定仓库后，在专业 Agent 设置中独立授权。从聊天的发送预览选择 Issue 或合并请求，先核对返回的文本片段，再确认随问题发送。备份恢复后，连接凭据与 Agent 读取授权需重新确认。

## 查询学习报告中的正式复习记录

在「学习报告 → 正式复习表现」点击独立通过、辅助作答、需要再练习或未评分，即可查看本周期对应的提交记录。通过「复习结果」也可切回全部。模型评价完成后，仍按原提交日归入报告。提前练习与专项练习各自保存。

每条记录可打开原课程。模型题组可查看当轮评价，再返回原周期和筛选。刷新报告或切换周期后会保留选中的复习结果。

## 从学习报告复习薄弱知识点

在「学习报告 → 薄弱知识点」选择「专项练习」。SQLite 样例提供两道独立题，可先查看原讲解，交卷后可重开同一入口查看成绩。模型课程可查看来源评价和已保存的补学讲解，点击生成后沿用课程的模型复习授权。专项练习单独保存，正式复习表现、课程路线和排期沿用原记录。

## 修订已发布课程

在阅读页选择「修订课程」，按整节或指定小节填写要求，预览主模型及独立复核的发送范围后开始。使用原课程任务额度。复核通过后可比较新旧段落与出处、查看关联笔记和受影响的复习目标，再选择接受新版或保留旧版。

接受后，旧正文仍可从「课程版本」打开。能唯一定位的笔记摘录可跳到新版，其余保留旧版原文并提示待重新关联。已学状态、原复习记录和作答保留。受影响题组等待用户确认新版依据。可从「今日任务 → 待查看课程更新」再次查看差异并标为已知悉。

## 从对话整理学习目标

在当前对话选择 **整理为学习目标** 后，可从可编辑目标卡选择 **用主模型整理目标**。发送预览显示目标字段、相关聊天原话和答复、已学记录。勾选 **附带资料片段** 后，可以查看将发送的正文。目标卡的「学习依据」支持移除引用，同时撤回进行中的目标整理。

模型整理使用一次主模型调用，遵循每日额度。返回的草稿标明原话提取、推断、建议和已有学习记录。采用草稿后可以编辑或语音改写。主题或预期成果仍有缺口时，目标卡显示一条补问。填完后单独提交才会生成路线。

## 重组学习路线

在项目页打开「路线版本与顺序」，选择「重组阶段与分支」。可为每节课选择或新建阶段，填入分支名称，或清空分支。用上下移动按钮设置实际阅读顺序。目录按该顺序显示阶段和分支。

预览会列出归属调整及受影响的阶段测评范围，确认后才写入路线版本。已有课程、笔记、已学状态、复习排期及测评尝试仍可查看。旧范围尚未发送的模型评审会停止。已发送请求的有效结果会留在历史测评里供查看。只改分支时沿用原阶段测评。

## 后台任务

从导航底部打开「后台任务」，可查看已就绪课程数和需要处理的原因。展开「管理」查看模型路线、草稿和独立核验进度，按当前状态停止、继续或重试。关闭抽屉后，正在运行的任务会继续执行。

达到单任务调用上限时，可停止，或修改上限后从已有阶段继续。删除前会预览待处理范围。确认后保留学习路线、已保存的课程、笔记和已发生的用量记录。

## 模型用量账本

在「管理中心 → API与模型」可为连接配置按百万输入和输出 Token 计的固定单价。账本按请求实际发送时的连接和单价记录，换连接或更新单价后仍可核对历史估算。

在「管理中心 → 额度恢复」可按北京时间日期查看模型用量，包括已确认发送的连接测试、外部语音转写和单页识别。每条记录显示服务商返回的 Token、语音秒数及可用金额。受支持的服务商回报标为实计，固定单价计算标为估算，其余标为未知。不同币种分别汇总。

## 语音与单页识别

本机识别效果不足或模型不可用时，可在录音窗口或知识库原页下点 **选择外部识别服务**。在「管理中心 → API与模型」填入相应用途的兼容连接。录音服务需支持 `audio/transcriptions`，单页服务需支持带图片输入的 `chat/completions`。两种用途可以选不同连接。

首次选择服务后，点 **预览发送范围**，核对接收地址、模型和范围，再点 **保存授权**。点 **发送此段录音** 或 **发送所选页图** 才会发出请求。授权可重复使用和撤销。连接变更或整体恢复后需重新确认。识别结果进入可编辑草稿，校对后可填入当前文字框或保存到本页。

外部识别计入共享并发和每日调用次数。启用适用金额上限且无法预估媒体费用时，外部请求会暂停，可继续使用本机识别或手动输入。

## Windows 桌面入口

将源码解包到有写权限的 Windows 本地目录或网络共享目录。在项目目录打开 PowerShell，执行其中一种。启动脚本在运行期间为 UNC 路径分配临时盘符，返回后释放。

```powershell
.\start-demo.cmd electron
.\start-demo.cmd tauri
```

Tauri 第一次构建需要 Rust MSVC、Microsoft C++ 构建工具和 WebView2。可以先在 Developer PowerShell 构建本机可执行文件，再运行启动脚本。

```powershell
cargo build --locked --manifest-path .\src-tauri\Cargo.toml
```

两个窗口共用 `dist/` 中的网页和同一个本地 FastAPI / Worker 实现。关闭窗口会隐藏到通知区域，计时和后台课程继续。通过托盘菜单打开或完全退出，也可从窗口菜单 **应用 → 完全退出**。重新启动同一桌面入口会恢复已有窗口。有活动计时时，退出对话框提供结束并保存、暂存待核对和取消三个选择。暂存的记录在管理中心确认保存。

浏览器、Electron、Tauri 的默认保存位置和启动设置目录分别为 `data/browser/`、`data/electron/`、`data/tauri/`。选择其他位置后，下次启动仍打开选定的工作区。工作区内的 `zhixue.sqlite3` 保存状态，`library/` 保存原件和学习文档。浏览器版可用 Ctrl+C 停止服务。每次启动自动签发本机会话，旧标签页会话失效时使用新打开的标签页。

源码模式可用 `uv run --locked python -m backend.voice_model` 准备本地语音模型，安装包内已包含该模型。模型约 181 MiB，准备完成后可离线识别。

### 恢复 Windows Tauri 旧版草稿

先在新版 Tauri 打开原知识库，再使用「完全退出」。如果笔记或复习在旧版保存后找不到，可从旧版 WebView2 资料目录导出。安装版默认使用 `%LOCALAPPDATA%\local.zhixue.desktop.tauri`。如果旧版用了自定义 WebView2 目录，`--profile` 填旧目录，`--data` 填新版应用数据目录。导出会把匹配的旧数据库复制到临时目录，再由本机 Chrome 读取。完整退出 Tauri 后执行，以便读取同一时刻的数据库文件。

在解包后的工程目录中执行。

```powershell
npm.cmd ci
uv sync --locked
$tauriData = Join-Path $env:LOCALAPPDATA 'local.zhixue.desktop.tauri'
$draftExport = Join-Path (Get-Location).Path '旧版Tauri草稿.json'
node desktop/tauri-draft-export.mjs --profile $tauriData --output $draftExport
uv run --locked python -m backend.tauri_draft_recovery --data $tauriData --export $draftExport
```

预览的 `ready` 列出可迁回的记录。加 `--apply` 写入后，可重新启动 Tauri 并从「手机离线」打开课程或复习。`conflicts` 按记录编号列出旧端口。需要恢复某个版本时，先在导出的 JSON 中核对该端口下的草稿，再同时传入 `--apply --choose '记录编号=端口'`。`keptCurrent` 表示新版已保存的记录或删除状态受到保护。重复导入同一版本会列在 `alreadyPresent`。导出的 JSON 含历史草稿，可留在本机核对各版本。

## 手机离线与电脑同步

电脑的「手机离线」页面可在本机下载课程和题组。使用独立手机时，在可信的 HTTPS 静态站点发布已构建的 `dist/`，用另一个 HTTPS 来源运行实时中继。手机页面需要 `/mobile/`、`/assets/` 和 `/zhixue.png`。

在源工程运行 `npm run mobile:package` 可生成带 Caddy 配置、手机离线资源和锁定中继依赖的 ZIP。 [手机 HTTPS 部署说明](deploy/mobile/README.md)

可在同一台电脑用三个回环端口复验。先构建前端，再分别在三个终端从工程目录启动。

```sh
uv run --locked python -m backend.launch --port 3220
uv run --locked python -m http.server 3222 --bind 127.0.0.1 --directory dist
uv run --locked python -m backend.mobile_relay --port 3221 --origin http://127.0.0.1:3222
```

在电脑页面选择「手机离线 → 同步 → 配对手机」，填写手机网页地址和中继地址。用独立浏览器资料目录打开生成的链接，申请配对，对照两端的配对码后在电脑批准。连接后可按需下载。电脑或中继离线期间可继续读、改笔记和作答，待发记录保存在手机浏览器。公开中继在单个进程内运行。可通过 `--tls-cert` 和 `--tls-key` 提供 TLS，或通过同机 HTTPS 反向代理转发到回环监听。代理应允许至少 15 秒的响应等待时间，并关闭同步路径的响应缓存与请求日志。

已下载的课程、笔记与题组可在手机上开始、暂停、继续及结束计时。电脑和手机在线时，新计时接手电脑上的正式活动计时。离线的手机时段先保存于本机，重连后按电脑已保存的时间区间去重。可在「管理中心 → 系统设置」核对重叠或需要校时的手机时段。确认的时间进入学习报告和计划估时。

手机在线时会共用电脑的复习提醒状态。当天首次前台交互时，复习提醒由一端显示，选择「30 分钟后」「明天」或关闭后，两端按相同状态继续。待处理的课程争议在电脑提醒，可直达争议处理页。电脑同时收到复习和争议时使用一张卡片，并一起保存所选提醒操作。手机在「同步 → 提醒设置」管理共享设置。点击固定课程提醒可打开课程，计时仍手动开始。

在已配对的手机打开「同步 → 手机系统推送」，点「启用手机推送」并允许通知。iOS 16.4 或更新版本从主屏幕上的智学 Web App 开启。电脑运行时，手机关页也可收到固定课程和已选择「30 分钟后」的复习提醒。留在「明天」的提醒仍在当天首次前台交互出现。手机可停用系统推送，电脑可撤销配对，共享设置可关闭全部学习提醒。 [Apple Web Push 开发文档](https://developer.apple.com/documentation/usernotifications/sending-web-push-notifications-in-web-apps-and-browsers)

订阅与发送密钥保存在电脑的系统凭据库。中继只转发实时加密配对消息，电脑向浏览器平台发送加密系统通知。锁屏通知使用通用文案。通知点击打开复习列表或预约课程，免打扰和提醒去重由电脑的同一份 SQLite 状态协调。

## 构建桌面试用包

在目标系统上使用同架构的构建工具。Windows 上需要 Node.js、uv、Rust MSVC 和 Microsoft C++ 构建工具。macOS 本机验证使用 Xcode 和本机 Rust。

```powershell
npm.cmd ci
npm.cmd run desktop:package -- all
```

也可以将 all 换成 electron 或 tauri。构建先生成共享的自带 Python 运行时的本地服务，再用独立临时目录复验资料导入、Worker 出课、加密备份与重启。Windows 的 NSIS 安装程序输出到 release/electron 和 release/tauri。Tauri 安装包包含 WebView2 离线安装器。macOS 本机构建将输出 .app 试用包。两个试用包使用各自的系统用户数据目录，另可在引导中选择实际工作区。可用加密备份在不同入口之间迁入学习数据。整体恢复后，回收站可继续找回与回收记录版本一致的原件。旧版换机后如果文件身份已变化，恢复时会提示核对内容版本和目标位置，再确认找回。
Windows 打包时，Tauri 的 Cargo 中间产物默认放在系统临时目录。每份工程使用独立缓存，减少依赖路径超过链接器限制的情况。若需使用其他短路径，可在运行打包命令的同一 PowerShell 中设置 `CARGO_TARGET_DIR`。

```powershell
$env:CARGO_TARGET_DIR = 'C:\zhixue-target'
npm.cmd run desktop:package -- all
```

相对的 `CARGO_TARGET_DIR` 以工程目录为基准。打包日志会显示实际输出目录。 Windows Tauri 安装包完整复制后才会替换 release 中已有的安装文件。


在采用 arm64 Node.js 的 Apple 芯片 Mac 上，可以构建供内部试用的 Electron 安装镜像。

```sh
npm run desktop:package -- electron-dmg
```

在已登录 macOS 桌面的会话中运行该命令。构建对应用和内置服务进行临时签名，并检查镜像完整性、只读挂载、「应用程序」链接、签名与 arm64 架构。镜像内的服务通过隔离回归后，打包器复制应用、卸载镜像，再核对副本签名并启动副本。通过隔离首次设置、新建知识库和应用退出时的服务停止检查后，生成 `release/electron/Zhixue-Electron-<版本>-macos-arm64.dmg` 和同名的 `.sha256` 校验文件。构建或校验失败时，该次构建目录留在 `release/electron/.dmg-*`。

### Apple 芯片 Mac 安装版验收

生成当前 DMG 后，在同一工程目录准备锁定的测试依赖，并从同一份源码构建配套手机 HTTPS 部署 ZIP。请在验收 Mac 上安装 Chrome。下例使用共享目录的 r2 DMG 和原始 0051 Electron ZIP。

```sh
uv sync --locked --group packaging --python 3.11
npm run mobile:package
share='/Volumes/personal_folder/Zlearning'
node desktop/mac-qualify.mjs \
  --dmg release/electron/Zhixue-Electron-0.1.0-macos-arm64.dmg \
  --r2-dmg "$share/项目状态快照/2026-11-18-macOS开发存档/候选安装包/Zhixue-Electron-0.1.0-macos-arm64-r2.dmg" \
  --legacy-zip "$share/桌面试用包/2026-11-17-路线阶段重组与课内助手/Zhixue-Electron-0.1.0-macos-arm64.zip" \
  --mobile-zip release/mobile/zhixue-mobile-https.zip \
  --reports ./mac-acceptance
```

验收核对两份 DMG、原始 0051 ZIP、手机部署 ZIP 和提取的旧服务摘要。两份应用均从只读镜像复制，卸载镜像后在独立知识库中运行。r2 跑 0051 迁移、复习和恢复对照。当前候选还运行首次使用、窗口重新打开、笔记、检索、复习与 OCR 的安装版用例。双链用例验证关键词及筛选续接、反向链接和重开后原文定位。延迟评分用例在安装版重启后核对原提交日的正式复习明细及评分日零重复统计，两项结果与安装服务摘要一同记入报告。离线计时用例在首次校时延迟后核对复测，丢失暂停回执后重启并检查原请求和学习报告秒数。当前候选先从安装副本的服务中逐项核对手机资源与部署 ZIP，并将两个摘要和文件清单记入报告。然后从服务中读取推送模块，复跑停用订阅与换配对后的迟到回执用例。两项结果与安装服务的 SHA-256 一同记入验收报告。Chrome 随后用从安装服务读回并逐项校验的资源启动独立手机站点，配对电脑端由同一安装服务启动。验收核对离线停用推送、移除本机配对和替换邀请后只清理已显示的目标配对通知。手机页、电脑服务和中继各使用独立回环地址。每轮生成独立的 `qualification.json`、Playwright 日志与结果，失败时保留已经取得的证据。实体麦克风和需人工操作的桌面用例按首版计划验证。

当前候选还须提供 OCR 校对的四项具名实装结果，覆盖并发保存冲突、搜索条件续接、迟到回执保留当前页、重启后读回校对版本与原件。报告同时记录实际安装服务的 SHA-256。

录音实装回归使用模拟麦克风和固定 WAV。当前资格报告记录窗口隐藏与最小化、初始化或录音时断开、断开后本机重录及确认填入、离开页面和退出服务。录音证据标记采集类型并绑定安装服务摘要。macOS 的 Chromium 音频服务在沙盒中运行，读不到工程目录里的固定 WAV，只能采到静音，因此该用例在 macOS 为测试进程关闭音频服务沙盒。正式应用和实体麦克风不受影响。

安装版用例一律用锁定 Python 的只读 URI 读取 SQLite。macOS 自带的 `sqlite3 -readonly` 无法打开已正常关闭的 WAL 数据库，会返回错误码 14。

当前安装版还要验证原件移出、改写后归位及下一次原子替换式保存。关闭并重新打开应用后，读回同一文件编号、文件摘要、原有双链及原文位置。验收报告将三项结果与安装副本的内置服务摘要绑定。


试用包目前使用无发布证书的构建流程。正式分发前应在目标 Windows 机器上安装并测量冷启动、资源占用、托盘恢复和计时退出。

macOS 当前安装验收按候选源码迁移头检查数据库，并要求从加密备份找回回收原件、核对复制原件和重启读回。历史 r2 对照按 0052 检查。

## 独立验收网页

在工程目录完成首次依赖安装和前端构建后，单独运行验收入口。

`uv run --locked python -m acceptance`

默认浏览器会打开 **智学独立验收**。选择 **运行核心验收**，可查看实际输入摘要、输出、状态、耗时与出错原因。展开流程分支查看争议、停止恢复和失败后的重试。运行历史按开始时间排序，节点按执行顺序回放，可导出 Markdown 报告。浏览和导出已记录的运行只读取验收记录。

每次运行把正式服务和数据库迁移文件复制到本机临时目录，并使用已构建的正式网页资源。正式启动入口在那里建立独立的 SQLite、知识库并启动 Worker，模型请求指向本机合成接口。完成后清理临时运行文件和学习数据。验收记录双链改名及反向定位，并核对正式复习明细在延迟评分后仍归入实际提交日。重启后再次读取两项证据。报告另记录回收站旧路径、独立工作区的加密备份找回，以及核对复制原件后重启读回。报告还记录原件移出、归位和再次保存，并在重启后核对同一文件编号、字节摘要、双链及知识库登记。历史默认保存在用户目录下的 `.zhixue/acceptance`，可用 `--reports <目录>` 指定历史位置。使用 `--no-browser` 可以在终端获取当次网页地址。真实模型样本在该回归中标为未验证。

展开 **知识库检索定位** 可查看「语义索引首次启用」。这个节点暂停临时库的首次 SQLite 提交，并行检查索引状态、关键词原文行和混合搜索的关键词回退。提交后核对缓存完整性、重复启用和原件 SHA-256。该节点停用嵌入模型下载，验证范围是缓存发布与检索连续性。

运行真实模型联调时，从终端退出验收程序会停止后续步骤。在 `--stdio` 模式关闭父进程的输入管道也会停止这次联调。已发出的请求继续保留在用量记录中。退出时尚未取得服务商回报的费用留待账单核对。重开原历史目录可以继续抽查已发布课程并导出账单核对表。

展开 **来源变更与课程修订** 查看真实资料改动、过期预览拦截、保留旧版、接受新版及关联恢复。这个分支继续使用隔离工作区内已经存有作答和排期的课程，并在整库恢复和进程重启后核对原链接。

展开 **模型金额额度** 查看单任务暂停、调高后续跑原草稿、每日额度拦截、北京时间跨日继续及整库恢复后的逐日用量。该分支使用新建的本机测试工作区和可控计费时钟，费用来自合成模型的 Token 回报与预设单价。

展开 **目标与路线调整** 查看目标日期预览和确认、已有知识点的顺序和标记、实战文件冲突与重试。实际 Worker 将实战写入知识库，重启后从同一测试工作区核对原笔记、复习排期和路线历史。

同一分支还会运行三条课内文字指令，并分别完成已会、提前和目标变更的预览确认。阶段重组节点展示实际的新旧测评范围、旧答题和两节课完成后生成的新测评。回放早期报告时，当次未执行的新增节点显示「未验证」。

单独选择 **联调真实模型**，可运行 SQLite 或国际单位制样本。填入主模型和独立复核模型，查看发送摘要并确认费用后才开始调用。每个样本最多 12 次模型请求，服务商可能计费。联调使用新建工作区，凭据只作为本次服务进程的内存配置。复习出题按已核验片段数等待，金额控制下串行返回的题目会继续计入同一运行。

真实模型联调开始发送时会保存脱敏的模型用量快照。整轮验收意外退出后，回放可读到最近保存的快照、采集时间和当时的账本状态。归档中断运行时保留同一运行 ID 的 `.usage` 文件，或导出 Markdown 报告。

存在调用记录的已结束联调可选择 **导出账单核对表**。CSV 保留运行 ID、接入范围、用量证据、角色和逐笔费用，服务商回报与本机估算分别列出。下载后按对应服务商账单填写空白的条目、币种、金额和结论列。报告显示配置中的连接是否包含回环地址，实际服务商与账单仍需人工确认。

完成后点击 **查看人工抽查**。按课程实际版本对照正文、引用和原始资料，记录事实、引文与适用条件的结论。人工抽查随验收报告导出。外部模型的实际联调结果以已存运行和人工抽查为准。

## Windows 桌面实测

在同一台 Windows 电脑分别安装两份 NSIS 产物，再使用 `npm.cmd run desktop:qualify:windows -- --help` 查看参数。分别传入 Electron 和 Tauri 的已安装可执行文件与原安装程序。评测核对两份安装使用相同架构和相同字节的 Python 服务，使用各自的临时知识库及浏览器资料目录，生成 Markdown 和 JSON。

默认交替运行三轮，记录可操作的首启界面、空闲和图谱负载的 CPU、内存、GPU、帧率与帧间隔。首轮复验真实文件、后台准备、窗口隐藏、计时退出和进程中断恢复。在 Windows 前台使用 `--use-tray` 可按提示操作通知区域图标，纳入恢复证据。
